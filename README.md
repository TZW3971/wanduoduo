# 玩多多 · 越玩越开心

一个给小朋友（和大朋友）玩的离线小游戏合集，纯前端、零依赖、不联网也能玩。  
19 个板块 / 18 款小游戏 + 电子书阅读器 + 便签，一套代码打包成网页、Windows 桌面端和安卓 App。

![版本](https://img.shields.io/badge/version-8.2-4f7cff)

---

| 方式     | 地址                              |
| ------ | ------------------------------- |
| 短链（推荐） | <https://tinyurl.com/wanduoduo> |

## ⬇️ 下载

各平台安装包在 [Releases](https://github.com/TZW3971/wanduoduo/releases) 页面下载：

| 平台              | 文件                        | 说明                                     |
| --------------- | ------------------------- | -------------------------------------- |
| iOS / iPadOS    | `玩多多-v8.2-iPhone离线版.html` | 单文件离线版（本仓库内），存进「文件」App 用浏览器打开，含 6 本电子书 |
| Windows 10 / 11 | `玩多多-v8.2-安装版.exe`        | 安装程序，建桌面图标，可正常卸载                       |
| Windows 10 / 11 | `玩多多-v8.2-便携版.zip`        | 解压即用，存档写在自身 `data` 目录，可放 U 盘随身带走       |
| Android         | `玩多多-v8.2.apk`            | 安卓安装包（本仓库内），约 6.4 MB                   |

安卓未知来源安装：需在系统设置里允许一次「安装未知应用」。

## ✨ 内容一览

- **益智**：2048、数字华容道、数独、记忆翻牌、连连看、五子棋、拼图
- **街机**：俄罗斯方块（支持左右滑动移动、点击旋转）、消消乐、打砖块、贪吃蛇、飞机大战、泡泡龙
- **休闲**：钢琴、刮刮乐、捏泡泡、养羊、迷你农场
- **工具**：电子书阅读器（书架 / 目录 / 划线 / 笔记）、便签、笑话库

## 📱 交互说明（移动端）

- 俄罗斯方块：手指左右滑动移动方块，轻点屏幕旋转，左下角切换方块，右下角速降
- 首页：上下滑动滚轮切换分页

## 🔐 数据与隐私

游戏进度、便签、书架收藏、阅读位置全部保存在**本机浏览器 / 应用本地存储**，不收集、不上传任何个人数据。  
线上版与 Windows 版额外支持「邮箱验证码登录 → 云备份 / 恢复」，用于换设备时迁移存档，数据仅存于你本人的账号下。
