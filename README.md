# 玩多多 · 越玩越开心

一个给小朋友（和大朋友）玩的离线小游戏合集，纯前端、零依赖、不联网也能玩。  
15 款小游戏 + 电子书阅读器 + 便签 + 笑话库，一套代码打包成网页、Windows 桌面端和安卓 App。

## ✨ v11.20 更新亮点

- **2048 数字雨**：一键落下 3~5 个随机数字块（2~32），绝境翻盘、可玩性拉满
- **2048 三档布局**：4×4 / 4×5 / 4×6 棋盘一键循环切换，自动记忆选择
- **合成大西瓜震颤修复**：物理引擎修正 + 地面摩擦，水果堆叠稳定不抖、滑动自然刹停
- 大西瓜水果雨（每次 6 个无冷却）、三套水果皮肤（笑脸/剖面/表情）等此前功能全部保留

## ✨ 内容一览

- **益智**：2048、数字华容道、数独、五子棋、消消乐
- **街机**：疯狂俄罗斯方块（滑动/按键双操作）、贪吃蛇、飞机大战、打砖块、泡泡龙
- **休闲**：钢琴、切水果、合成大西瓜、养羊
- **工具**：电子书阅读器（书架 / 目录 / 划线 / 笔记）、便签（含待办清单）、笑话库

## 📱 交互说明（移动端）

- 俄罗斯方块：左右滑动移动方块，下滑速降，键盘 ↓ 速降
- 笑话：上下左右滑动切换，双指捏合调字号
- 首页 / 合集：横滑翻页

## 🔐 数据与隐私

游戏进度、便签、书架收藏、阅读位置全部保存在**本机浏览器 / 应用本地存储**，不收集、不上传任何个人数据。  
线上版与 Windows 版额外支持「邮箱验证码登录 → 云备份 / 恢复」，用于换设备时迁移存档，数据仅存于你本人的账号下。
